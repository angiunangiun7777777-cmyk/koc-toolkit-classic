# YouTube KOC 挖掘工具（韩区通用版）

浏览器直接运行的韩国 YouTube KOC 挖掘工具。纯静态网页，无后端，密钥只存在使用者自己的浏览器里。

## 在线使用

打开 https://angiunangiun7777777-cmyk.github.io/koc-toolkit-classic/

## 功能

- 填自己的 YouTube Data API v3 密钥（页面内有申请教程）
- 输入竞品游戏名（中英韩自动翻译成韩语搜索词）或点选题材品类
- 搜视频反查频道，自动分类、算均播、判平台、识别地区、排除非游戏号
- 出结果表，可导出 CSV，筛选记录存本机浏览器

## 源码

就是根目录的 `index.html`，单文件，双击也能本地打开。
