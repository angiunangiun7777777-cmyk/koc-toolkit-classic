2026-09-15 v10新增「地区精准识别」，解决「欧美澳加的 YouTuber 都讲英语、只靠语言分不出国家」这个问题。先说清楚一个前提：YouTube 公开接口不提供任何人的 IP，观众地理分布只有频道主本人在后台看得到，所以「按 IP 抓」这条路在挖掘端根本不存在，工具因此改用三层可观测信号做判定，并给出置信度分档。

第一层是频道的 country 字段，也就是创作者自己填的所在国，这是唯一能当硬数据的信号，实测在英语搜索召回的频道里覆盖率约 82%，能把美国、加拿大、英国、爱尔兰、澳洲干净分开。第二层是文本线索，用来给 country 缺失的频道补位、也用来给有 country 的频道做交叉验证，包括拼写差异（color 对 colour、favorite 对 favourite）、货币（$ / C$ / £ / A$）、华氏度（基本只有美国在用）、电话国际区号（+44 / +61 / +353）、外链域名后缀（.ca / .co.uk / .com.au）以及简介里的城市和州名。英国和澳洲的创作者几乎不会写美式拼写，所以这套规则对英语区的区分度相当好。第三层是可选的跨区召回校验，同一批搜索词分别在美区、加区、英区各搜一遍，看某个频道只在哪个区稳定出现；这层默认关闭以省配额，需要时打开即可。

判定结果按高、中、待确认三档标注，信号不足的如实标待确认而不硬归类，避免污染投放决策。结果表、CSV 导出、分享报告和历史记录都新增了「地区」和「置信度」两列，鼠标悬停地区标签就能看到具体的判定依据。搜索地区下拉同时扩展为美国、英国、加拿大、澳洲、爱尔兰、新西兰等多个国家，切到非韩文区时会自动关闭「只保留韩文标题频道」这道过滤，否则当地频道会被整道挡掉。

有一点必须提醒：这三层判定的是「创作者在哪个国家」，不等于「观众在哪个国家」。观众地区公开渠道永远拿不到，所以投放时请在 Google Ads 端用地理定向兜底——广告定向到该频道的版位，同时限制只展示给目标国家用户，非目标地区不计费，这样频道的地区属性就从硬门槛变成了成本变量。

📘 YouTube Data API v3 密钥获取教程

整个过程约 3 分钟，需要 Google 账号和一张能收短信的手机号（仅首次创建项目时验证）。全程免费，不会扣任何费用。

1
打开 Google Cloud Console
浏览器访问 https://console.cloud.google.com/，用你的 Google 账号登录。第一次访问会让你接受服务条款，勾选同意即可。
2
点击顶部「项目下拉框」→ New Project
点开页面顶部标着项目名的下拉框，弹出菜单里选 New Project（新建项目）。每个项目独立计费、配额独立，建议每个挖掘工具单独建一个。
3
填项目名 → Create
项目名随便起，比如 koc-tool 或 my-koc-2026，方便辨认即可。Project ID 是自动生成的，不用改。组织选 No organization（个人用）。点击底部蓝色 CREATE 按钮。
4
侧边栏 → APIs & Services → Library
项目创建完成后会自动跳转。点击左上角 ☰ 三横线（导航菜单），展开后找到 APIs & Services → Library（库）。
5
搜索 YouTube Data API v3 → ENABLE
在搜索框输入 YouTube Data API v3，点搜索结果第一项进入详情页，再点蓝色 ENABLE 按钮。启用成功后会自动跳转到 API 概览页。
6
左侧 Credentials → + CREATE CREDENTIALS → API key
启用 API 后，侧边栏点 Credentials（凭据），顶部点 + CREATE CREDENTIALS，下拉菜单选 API key。
7
复制弹窗里的 API Key
弹窗会显示一串以 AIza 开头、39 位左右的字符串。点右侧 📋 图标复制完整字符串，粘贴到工具里 ① API 密钥 输入框即可。弹窗关闭后，密钥会保留在凭据列表里随时可查。
建议：限制 API Key 的使用范围。 创建好密钥后，点密钥名进入编辑页，API restrictions 选 Restrict key，下拉里只勾选 YouTube Data API v3。这样即使密钥不小心泄露，别人也只能调用这一个 API，安全性高很多。配额和功能不受影响。
